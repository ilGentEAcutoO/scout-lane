# Security

Report vulnerabilities privately. Do not open a public issue for a live
exploit, leaked key, or auth bypass.

Email **suanwin.paows@gmail.com** with:

- affected Worker / route
- steps to reproduce
- impact (session, data, keys)

You should get an acknowledgement within a few days.

## Please do not

- commit API keys, session secrets, or Google OAuth client JSON
- publish employer assignment PDFs or candidate PII
- run unapproved scrapers / LinkedIn cookie capture against this codebase
