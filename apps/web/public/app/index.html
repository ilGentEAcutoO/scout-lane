    วาง URL นี้เป็น custom connector — ไคลเอนต์จะค้นพบ OAuth แล้วเด้งหน้าเข้าสู่ระบบ Scout Lane ให้เอง ไม่ต้องวาง token

    http://127.0.0.1:8790/mcp

    1. Claude: Customize → Connectors → Add custom connector → วาง URL
    2. ChatGPT: Settings → Apps & Connectors → Create → Auth = OAuth → วาง URL
    3. Gemini / Grok: เพิ่ม custom MCP แล้ววาง URL เดียวกัน

    คอนเนกเตอร์บนคลาวด์ต้องเป็น HTTPS — ของเครื่องนี้ใช้ได้กับ localhost ตอนรัน npm run dev:mcp

    หรือสร้าง PAT ด้านล่างถ้าเครื่องมือยังไม่รองรับ OAuth
